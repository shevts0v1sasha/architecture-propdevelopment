# Требования к безопасности

## Взаимодейтвия сервисов
Взаимодействие должно происходить с применением методов шифрования по защищенным каналам. Обязательно использовать TLS. Все запросы должны проходить через gateway api с логированием данных о запросе.

## Мониторинг
Реализовать журналирование всех операций независимо от успеха или отказа. Хранение логов минимум 180 дней. Предоставить доступ к логам для проверки и анализа.

## Доступ
Доступ должен быть организован в соответствии протокола OAuth 2.0 и передаче JWT токенов. Срок жизни токена доступа не более 5 минут. Если необходимо аутентифицироваться, то используем протокол OpenID Connect.

## Ролевая модель
Использовать подход минимальных прав для каждого пользователя.

## Требования к хранению ключей
Смену ключей шифрования проводить раз в 6 месяцев. При утечке ключа - сразу.
Ключи хранить в специальных защищенных хранилищах.
