# Чек-лист безопасности

## Разделы с описанием

**Управление доступом** - много точек регистрации, инциденты с отображением чужих данных в личном кабинете, отсутствие
централизованного контроля учетных записей и регистрации.

**Безопасность данных** - часть сервисов находятся на собственных серверах, часть на облаке. Данные ходят между
сервисами без контроля и шифрования.

**Защита инфраструктуры** - критичны пункты по сетевой защите, изоляции, сегментации, мониторингу

**Управление инцидентами** - нет автоматиизации реакции на инциденты, мало контроля

**Специфические аспекты** - нужно проработать вопрос с MDM, VPN
